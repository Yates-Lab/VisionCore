# FIXRSVP twin pathway supplement

This folder contains the manuscript-selected NO_PHASE_R1_s201 analysis, its behavioral tests, and the eight-panel figure source. `caption.md` describes the displayed panels. The checkpoint SHA-256 is `e70f287462155607a96c7d23d9d56e347111319aa48cafd3f54fe88dd4484cb9`. The model and Figure 3 score cache may live in a separate selected-analysis repository; `VISIONCORE_MANUSCRIPT_SOURCE_ROOT` selects that repository. The aligned empirical cache defaults to `VISIONCORE_CACHE_DIR` (or `VisionCore/outputs/cache`); `VISIONCORE_MANUSCRIPT_EMPIRICAL_CACHE_DIR` selects a separate input directory. The processed FIXRSVP dataset root is passed explicitly, without changing the checkpoint's dataset config. During inference, `prepare_data` loads FIXRSVP through the configured `DataYatesV1` session registry. Before preprocessing, the compute command requires the registry's `datasets/fixrsvp.dset` and the file under `--data-root` to be the same file (symlink aliases are accepted). A different dataset fails before inference, even if its observations appear to match.

## Portable invocation

In another checkout, set the selected-analysis source root and processed root to that machine's actual locations. The latter must resolve to the same FIXRSVP file as its `DataYatesV1` registry when computing incomplete sessions.

```bash
cd /path/to/v1-fovea/VisionCore
export PYTHONDONTWRITEBYTECODE=1 PYTHONPATH="$PWD" NVIDIA_TF32_OVERRIDE=0
export VISIONCORE_MANUSCRIPT_SOURCE_ROOT=/path/to/selected/VisionCore
DATA_ROOT=/path/to/registered/YatesMarmoV1/processed
uv run --project "$(pwd)/.." --no-sync python -m paper.supp_twin_saccade_modulation.compute --session Allen_2022-04-06 --data-root "$DATA_ROOT"
```

Use the same `--project`, `PYTHONPATH`, selected source root, and data root for the other commands above. `plot` renders the top-10 CCnorm candidate gallery, example traces, and population. `figure` assembles eight panels using the validated cached cohort and defaults to Allen_2022-04-06 CID 98 (ordinal 90; CCnorm 0.861572, CCmax 0.936804); `--session NAME --cid INTEGER` accepts another empirically and event-eligible cached unit, including units outside `selection.json`'s top ten. The default shows 56 chronological trials and 50 complete peri-saccadic events over 0.2458333–0.8 s (native bins 59–192). Panel A displays raw observed counts divided by each 240-Hz bin width (4.167 ms): one spike per bin is 240 spikes/s, without smoothing or inferred spike times. Observed and full predicted rates share a linear grayscale scale from zero to 500 spikes/s (500+ marks saturation); supported values above 500 retain their raw values but take the darkest shade. Gray masks unsupported bins. Gain and additive maps share a signed-effect colorbar. All four maps share the Trial time (s) axis and the same small hollow green right-pointing onset markers. C, D, E, and G label time from saccade onset; C and D have saccade-aligned pathway titles and no redundant legends. Its joint signed-map limit is ±30.283 spikes/s; the raw predicted/observed mean rate ratio is 1.280454. Panel B's curves retain the pooled support-weighted five-bin means; shaded bands show ±1 sample standard deviation of separately smoothed displayed-trial rates (observed spike-count noise versus model predicted-rate variability, not confidence intervals or simulated spikes). Panels C–D retain their 400-trial-bootstrap bands and use identical symmetric vertical limits around zero that include both traces and bands. Horizontal padding between B/C/D keeps their axis labels and ticks separate. The full figure is 8 × 10.5 inches, sized for 0.25-inch margins on US Letter. Other examples retain their own native crop and per-unit signed-effect limits; the 500-spikes/s observed/full display cap is common to all. Regenerate `plot` before `figure` if the caches change.

Any earlier `window_means.npz` is historical and is not plotted.
- `VisionCore/outputs/figures/supp_twin_saccade_modulation/`: gallery, example traces, population and `assembled/fixrsvp_full.png|pdf`.
- `VisionCore/outputs/figures/supp_twin_saccade_modulation/candidate_review/`: `top50_examples_A-D.pdf` (rank equals page, no cover), plus `page1_preview.png`. The companion `outputs/stats/supp_twin_saccade_modulation/candidate_review/` contains `candidate_index.csv` and `manifest.json` with per-page trial/crop/support counts, numeric hashes and validated source hashes. This separate historical review was rendered when CID 93 was the default; its page-2 “Current example” tag and original spike-raster visual encoding record that earlier rendering, while the assembled figure now uses CID 98 on page 30 with binned spike counts. It does not change `selection.json` or the assembled figure. Future gallery renders use per-page raw PSTH axes, a shared zero-centered C/D vertical range per page that contains both bootstrap bands, each page's signed-map joint 99th-absolute-percentile scale, and the common 0–500 spikes/s capped observed/full map scale (count × 240 Hz versus raw predicted spikes/s). Rates above 500 remain unmodified in the arrays but saturate the display. The saved historical gallery remains unchanged. The event traces average all qualifying events, not just the displayed trial-map detections.

`VISIONCORE_CACHE_DIR`, `VISIONCORE_STATS_DIR`, and `VISIONCORE_FIGURES_DIR` override the respective canonical **base** directories for isolated runs. Set `VISIONCORE_MANUSCRIPT_EMPIRICAL_CACHE_DIR` separately when overriding the cache output root, or the aligned input cache will be sought in the isolated output root. Completed sessions are reused only after each source dataset/detection hash, selected input digest in its original manifest order, component hash, and result hash match. Recorded input paths in imported manifests remain intact; only their verified digest values are matched to relocated paths. Invalid or partial caches abort rather than being overwritten. The 19 verified session caches and current figure artifacts were copied from the original pilot run, not moved.

The zero-behavior reference uses the biased behavioral encoder at zero input, not an assumed identity gain. Before softplus, `zfull = z0 + delta_additive + delta_gain`; the four saved raw native-count rates are `r0`, `r_additive`, `r_gain`, and `rfull`. The interaction is `rfull − r_additive − r_gain + r0`. Gain/additive displayed effects are `(r_gain − r0) × 240` and `(r_additive − r0) × 240` spikes/s, respectively. No calibration, extra baseline subtraction, or population row normalization is applied. Inference checks source CIDs/observations, stimulus crop, native contiguous 60-bin histories, and direct full/zero forward identities with TF32 disabled. The strict identity threshold is 2e-4.

The empirical cohort requires rate >2 Hz, split-half PSTH R² >0.10, and at least 10 qualifying units per session (1,022 units across 19 sessions). Detector records require finite fitted onset/endpoints, 0 < displacement <1 degree and ≥150 ms from *any* detected onset. These are saved fits, not manually verified events. Complete −100/+200 ms same-trial event windows require contiguous 240-Hz inference, valid eye/DPI and every condition/observation/filter supported at every bin. At least 20 wholly supported events per unit retain 773 units from 15 sessions. Individual-unit event means form population rows; **units are not averaged within sessions**, and there is no session-cluster interval or cross-session test. Five-bin smoothing is applied within each complete event before averaging. The top-10 gallery is ranked by finite CCnorm ≤1 and CCmax >.85 after empirical/event eligibility; CCnorm neither gates the population nor rescales predictions. Population rows sort by the lag of their positive gain maximum in 0–200 ms (latest first), then 16 nonpositive rows without a separator in the composite. Individual example intervals bootstrap trials (400 resamples), retaining their constituent events. The stimulus-aligned PSTH averages observed and predicted native counts on the same map support and uses support-weighted five-bin smoothing; ±1 sample-SD bands describe the displayed trial rates after separately smoothing each trial, with undefined SD for fewer than two supported trials. The composite shows four matched trial maps with identical hollow green markers for all displayed detected onsets (not just qualifying events), then the matched PSTH and separate gain/additive traces with bootstrap bands. The lower rows pair gain and additive heatmaps (seven grid columns each) with scatter plots and bottom/right marginal histograms (five columns each). Example traces and heatmaps display the full −100 to +200 ms around onset without truncating the saved event windows, bootstrap traces or population rows; trial maps and PSTH retain their 0.2458333–0.8 s display. Each scatter plots signed balance (P−N)/(P+N) against total modulation P+N in spikes/saccade, where P and N are enhancing and nonnegative suppressive areas of existing five-bin-smoothed event-mean population rows over inclusive native lag centers from 0 to 200 ms. Both areas use trapezoidal quadrature with lag in seconds. No extra smoothing, filtering, normalization, baseline correction or sign threshold is applied. Balance runs from −1 (negative only), through 0 (equal contributions), to +1 (positive only), and is undefined for exactly zero total (none of the 773 rows). Both pathways share the same dimensionless horizontal range and linear vertical limits, without equal data aspect across unlike units. Marginal histograms aligned below F/H show fraction of units in each of ten common equal-width signed-balance bins from −1 to +1, with +1 included in the final bin; they share a linear fraction scale. The histograms to the right show fractions of all 773 units in shared 0.05-spikes/saccade total-modulation bins, starting at zero and extending through the largest total; both have the same linear fraction limits and include the highest observation in the final bin. The balance-histogram denominator is the number of units with defined balance (all 773 in the current population). Median gain/additive balances are −0.040/−0.784; median total areas are 0.325/0.073 spikes/saccade. Additive balances cluster toward both ends, especially the negative end. These measures do not encode temporal order or peak count, and do not test individual biphasicity or population bimodality. The eye-velocity basis is acausal; event-aligned timing is descriptive and cannot establish a causal neural latency. Pathway counterfactuals are properties of this model rather than measured biological response gains or offsets.
